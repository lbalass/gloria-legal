# GLORIA — pages légales

Les documents publics du jeu mobile **GLORIA** (`com.lbalass.gloria`),
hébergés par GitHub Pages pour être référencés depuis la fiche Google Play.

- `index.html` — Politique de confidentialité
- `conditions.html` — Conditions générales d'utilisation et de vente (gemmes, passe de saison, rétractation, garantie, médiation CM2C)
- `mentions-legales.html` — Mentions légales (éditeur, hébergement, médiateur)

**La source fait foi ailleurs.** La politique est générée depuis
`docs/POLITIQUE-CONFIDENTIALITE.md` du dépôt du jeu ; les conditions et les
mentions légales reprennent les informations de l'écran MENTIONS LÉGALES du
jeu (`scripts/screens/account.gd`, `_legal_screen`). Toute correction se fait
là-bas, puis se republie ici : deux textes qui divergent, c'est celui que le
magasin référence qui fait foi.
